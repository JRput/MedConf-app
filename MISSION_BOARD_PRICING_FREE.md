# MISSION BOARD — False "Free" pricing (ELCC 2027 and 108 other events)

**Date:** 2026-10-27
**Brief:** Owner spot-checked European Lung Cancer Congress 2027 (conference 891, ESMO source 17): the site shows "Free" / "Standard £0.00" while esmo.org publishes a 9-row × 3-column EUR fee table. Review why, correct the data, and make future scrapes collect ESMO pricing accurately.
**Classification:** software (scraper data quality)
**Status:** IN PROGRESS

---

## Root cause (established by the Commander, 2026-10-27 — facts, not hypotheses)

1. **The £0 tier was written by the remediator, not the scraper.** `reports` artifact of GitHub run 39111378804 (remediator-daily, 2026-10-18): `patches_applied` for 891 = `[{'tier_label': 'Standard', 'price_gbp': 0.0, 'currency': 'GBP'}]`, `method: free_event`. Same for ESMO Breast Cancer 2027 (893) three minutes later. `remediator/fixers/pricing.py::fix_pricing` step 1 returns a £0 "Standard" tier whenever `_FREE_RE` ("free of charge", "free to attend", …) matches ANYWHERE in the page text, BEFORE it looks for prices. The ESMO registration page contains a fee-table row "Press Representatives | Free of charge" next to nine € rows. 33 `free_event` patches were applied in that single run across sources.
2. **The scraper had no ESMO fees to begin with.** `extractors/esmo.py::_pricing_from_registration_text` only recognises enumerated row labels (`ESMO Member…`, `Non ESMO Member…`, `Members affiliated to…`). ELCC's rows read "ESMO / IASLC / ESTS / ESTRO Member", "ESMO/ IASLC Member Nurse", "Non-Member Academia & Other (non-Industry)*", "Non-member Industry**" → zero matches. ESMO Breast 2027's page uses the recognised labels but was published AFTER the row's last detail scrape (2026-10-04) and nothing re-details a row whose fees are missing (`scraper.py` self-heal only re-fetches when format/venue/city are missing).
3. **CORRECTED 13:41 — the Kontent API is alive.** During the investigation (~11:30) `kontent.cdn.aws.esmo.org` returned a connection failure (HTTP 000) and the board recorded it as a CMS-migration casualty; the production run at 13:28 matched 70/70 listings against it and a direct call returns 200. It was a transient outage. The hardening it motivated (one warning per run, page-based `_facts_from_rendered` fallbacks, `_evidence` keys, non-destructive re-detail) stays as resilience and is exercised whenever Kontent lacks a field (`venue_name` is empty on several new rows because Kontent's venue field is empty, not because the API was lost — follow-up). Main-page Nuxt-payload fee parsing (`_pricing_from_esmo_fee_table`) also ran AFTER the sub-page parse and overrode it, which explains the duplicated/mixed labels on ESMO Congress 2026 (869).
4. **Blast radius (live DB, 2026-10-27):** 1,141 zero-price tiers exist, most legitimate (RSM member-free rows). **109 active events have a lone "Standard £0.00" tier and therefore render "Free"**: 24 timed with a remediator pass (free_event), 85 written by per-source extractors (RCPath 20, RCR 18, RCPCH 13, BIASP 10, SCCM 9, ESMO 8, BSG 6, ERS 5, RCP 4, …) — some of those are genuinely free webinars; each needs page evidence before it is touched.
5. Website behaviour is correct given the data: `EventSidebar` labels min price 0 as "Free"; `directory_events.price_from = 0` → "Free" filter bucket.

## Success criteria — Definition of Done
1. ELCC 2027 (891) and ESMO Breast 2027 (893) show the real EUR fee tiers on medconf.vercel.app (27 tiers each: 9 categories × Early/Late/Full, `early_bird_deadline` set on Early).
2. `fix_pricing` can no longer return a free tier when the page shows currency amounts; the matched "free" sentence is logged; a unit test with the ELCC registration fixture proves it; the 2026-10-04 SCCM regression stays covered.
3. The ESMO parser is table-driven (any row label + N amounts under an Early/Late/Full header, EUR/SGD/USD/…) with fixture tests for ELCC 2027 and Breast 2027; registration sub-page tiers take precedence over the main-page payload.
4. Rows with no fees are re-detailed on a cadence for sources that opt in (ESMO opts in), so late-published fee tables are picked up without a listing change.
5. Every one of the 109 lone-£0 events is classified with page evidence (WRONG_FREE / LEGIT_FREE / UNKNOWN); WRONG_FREE tiers are deleted (price becomes "unknown", never "Free") and those rows are queued for re-detail; LEGIT_FREE untouched; UNKNOWN listed for the owner.
6. Audit gate flags "stored as free but page shows fee amounts" so this class of miss is visible in future runs.
7. All scraper tests green (`pytest --ignore=test_api.py` — test_api.py has a pre-existing collection error unrelated to this mission).
