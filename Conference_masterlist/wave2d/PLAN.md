## Post-wave follow-ups (Commander-owned, after the gate)
- **single_congress family fix:** 7/13 batch-S sites needed the same `parse_place` hook ("Venue, City, Country") and several hit listing-path date gaps; full evidence in `_family_gaps_single_congress.md` (12 sections). One careful change to `single_congress.py` + regression on 3 live single-congress sources (89–102) + its tests; then retire the duplicated hooks.
- **UK region map consolidation:** a dozen extractors carry their own place→region table (`_UK_REGIONS` / `_UK_PLACES`); create a neutral `extractors/uk_regions.py` and migrate. Per-source modules never import each other (review found baaps→rcpath and bsg→ems_calendar; both replaced with local copies during the wave).
- **Relevance gates:** BOA and BAAPS calendars list third-party promoter events; both now drop off-topic rows (Commander-approved 2026-10-21) and log dropped titles. Watch CI logs for false drops.
- **Cross-source duplicates:** BMFMS (125) and BAPM (128) both list "Beyond the CTG", the Perinatal Symposium and the BICS conference under different URLs; `source_url` is the only dedupe key, so both rows publish. Needs a general design (title+date match across sources in the directory view or a scraper-side canonical key), not a per-source hack. Likely already affects older society pairs.
- **Shared-helper gaps reported by batch A (not changed during the wave):** `pricing_tables.parse_pricing_tables` keeps only the last price column when headers are not timeframes (lost BSSH full-meeting rates) and drops the Category column of Ticket/Category/Price tables (collapsed BAUS tiers), sometimes takes a nearby sentence as the section name; `abstract_classifier` reads "once the abstract deadline has passed…" as a closed call (ABS conference open until 23 Nov 2026 came back closed); `http_fetch.fetch_html` treats Chromium's XML viewer as a challenge page unless `expect_selector` is set (sitemap.xml). `classify_specialty` returned Cardiology/Oncology for hepatology events on single-specialty societies — builders fell back to the society constant.
- **LLM chain rotation 2026-10-21:** nemotron-3-super-120b and muse-glimmer-30b returned 404 during batch A; agent `model-rotation` dispatched (runbook: memory/project_kimi_eol.md).
- **New source candidates found during the wave:** EULAR Annual Congress (Berlin, June 2027) lives on `congress.eular.org`, not on eular.org/event → a `single_congress` subclass in a later batch. nihr.ac.uk (138) and endocrinology.org (123) stay unregistered (CloudFront 403 / Cloudflare challenge from runner AND home IP); re-probe in a month.
- **Terms-of-use / "no AI" sites (owner decision):** AAN (140), AAD (141), CNS (142) forbid feeding content to AI tools (AAN also forbids automated access; robots.txt blocks GPTBot/ClaudeBot/anthropic-ai). AUA (105, batch S) carries a similar AI-use notice and is already active. Extractors use no LLM, but shared steps (merge, remediator description fixer, vision) could send their text to a model. Reviewer C2 read the actual terms: **AAN** forbids any robot/scraper/automated access and text-and-data mining without written consent (robots.txt also blocks 23 AI agents); **AAD** forbids incorporating Academy content into any third-party database/compilation/AI model without attribution or for commercial purposes; **CNS** forbids integrating content into external applications, bots, software or websites (AI named as an example). So for AAD/CNS the issue is the directory itself, not only the LLM. Registered INACTIVE; owner decides whether to list at all (attribution + non-commercial may satisfy AAD). If any is activated, a per-source `no_llm` flag in `scraper.py` merge + remediator comes first.
- **Shared fee-grid parser:** `pricing_tables.parse_pricing_tables` mislabelled ASH deadlines, dropped "Complimentary" rows and found no CNS tables; builders duplicated a grid parser in hematology/aad/cns. Fold the improvements back into the shared parser after the wave (with the batch-A findings above).
- **Specialty taxonomy (website):** batch A raw specialties include Hand Surgery, Breast Surgery, Hepatology, Transfusion Medicine, Infection Prevention and Control, Vascular Surgery plus LLM variants ("Vascular", "Vascular Medicine", "Urological Surgery", "Liver Disease", "Surgical Systems", "Medico-Legal").
